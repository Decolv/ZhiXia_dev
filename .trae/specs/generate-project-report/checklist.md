# Checklist

- [x] PDF报告生成脚本成功运行无错误
- [x] 生成的PDF文件包含项目概述章节（名称、版本、核心特性）
- [x] 生成的PDF文件包含技术栈详情章节（ASR、LLM、TTS、Agent、RAG、WakeWord等）
- [x] 生成的PDF文件包含系统架构章节（模块化架构、插卡式架构说明）
- [x] 生成的PDF文件包含开发进展章节（基于specs的完成情况统计）
- [x] 生成的PDF文件包含性能指标章节（延迟、内存占用等数据）
- [x] 生成的PDF文件包含关键文件结构章节
- [x] PDF中文显示正常，无乱码
- [x] PDF格式整齐，有清晰的标题、段落和列表结构
- [x] 脚本在无PDF库时给出清晰的错误提示和安装命令
