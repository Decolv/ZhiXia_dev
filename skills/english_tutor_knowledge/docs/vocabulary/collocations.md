# 词汇搭配

## 词汇列表

### make a decision
- 搭配: make a decision
- 音标: /meɪk ə dɪˈsɪʒn/
- 词性: phrase
- 释义: 做决定
- 例句: We need to make a decision by tomorrow.
- 翻译: 我们需要在明天之前做出决定。
- 记忆法: make(做) + decision(决定) → 做出决定
